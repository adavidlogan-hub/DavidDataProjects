# Decisions log

Each entry: date (UTC), decision, reason.

1. 2026-10-02. Stdlib-only fetch client (urllib, sqlite3, tomllib). Reason: the poller must run on a dedicated Windows laptop with a one-command install; fewer dependencies means fewer install failures. Python 3.11+ is required for tomllib.
2. 2026-10-02. All limits live in config/fetch.toml. Host classes: county (default, 1 request per 3 s, concurrency 1), vendor (concurrency 4, exponential backoff), archive (1 request per 2 s, back off on 429, honors Retry-After), sos (treated like county). Unknown hosts fall into the county class, which is the most conservative.
3. 2026-10-02. Rate-limit state is stored in the shared SQLite index (var/cache/index.sqlite) rather than in memory, so several agent processes running at once still share one per-host limit. A test proves the interval holds across two separate processes.
4. 2026-10-02. robots.txt follows RFC 9309: 4xx means allow all, 5xx or unreachable means disallow all. Failed robots lookups are cached for 10 minutes so a down host is not hammered.
5. 2026-10-02. Retries: 2 retries (3 attempts total) on network errors, 408, 429, and 5xx; other 4xx fail immediately. Every final failure goes to var/logs/fetch_failures.jsonl and the fetches table.
6. 2026-10-02. Cache is content addressed by SHA-256. Every fetch attempt is logged with a timestamp; identical bodies are stored once. A cached page is returned instead of refetched unless the caller passes use_cache=False, in which case ETag and If-Modified-Since are sent.
7. 2026-10-02. The container running this build cannot reach any target host (county sites, sos.state.tx.us, web.archive.org, archive.org) because the environment's network policy rejects them. See BLOCKERS.md item 1. The pilot proceeds with the one channel that works, a server-side web search tool. Its results are recorded verbatim through txprecinct/searchlog.py into the same cache so no agent repeats a query. This is a deliberate, logged exception to "all agents use the fetch module": the search tool is not reachable from Python.
8. 2026-10-02. Because Wayback CDX timing (Phase 1 step 3) cannot be fetched, research agents may tag LIVE_PRECINCT or PRECINCT_END_OF_NIGHT only from an explicit, citable statement or a timestamped document about election-night precinct posting. Confidence is capped at med for any tag that is not backed by a directly inspected primary source with timestamps, and fields that need a page fetch (exact usage notice text, snapshot timestamps) stay blank unless a source quotes them verbatim. Anything else is UNKNOWN.
9. 2026-10-02. Facts that appear only in the search tool's generated summary (not in a result title, URL, or quoted source text) are treated as leads, not evidence. They may not by themselves support a tag or a phone number or email.

24. 2026-10-02. 39. 2026-10-02. Live precinct view rule (check 3). Harris's live results app was archived on election night (2026 primary 8:01 PM, runoff 8:47 PM) with a "Precinct Reporting" tab that loads per-precinct candidate votes (rep-pv-<contest>.json, dem-pv-<contest>.json) from the same live, cache-busted data folder as the county totals. The per-precinct files themselves were not archived, so the number of releases cannot be counted. Rule adopted for all counties: such an archived live precinct view counts as LIVE for that election from check 3, with county confidence capped at med. A per-precinct turnout table alone does not qualify. The owner stated that Harris releases its results; that statement is not used as evidence.
40. 2026-10-02. Confidence is computed, not chosen by agents, because agents read "med" three different ways. Rule (phase1/schema.py compute_confidence): low when the tag is UNKNOWN or only one election decides it; high when two or more deciding elections were all settled by check 1 or by check 3 content; med when two or more deciding elections include a check 2 result, or any deciding election rests on the live precinct view rule. Applied in the build and in verifier selection. Effect at the time of adoption: 60 counties move from low to med (two or more elections agree through county-posted reports); no county moves down.
